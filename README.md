# «Пара» — цифровой деканат (концепт хакатона)

![концепт для хакатона, данные вымышленные](https://img.shields.io/badge/%D0%BA%D0%BE%D0%BD%D1%86%D0%B5%D0%BF%D1%82%20%D0%B4%D0%BB%D1%8F%20%D1%85%D0%B0%D0%BA%D0%B0%D1%82%D0%BE%D0%BD%D0%B0-%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5%20%D0%B2%D1%8B%D0%BC%D1%8B%D1%88%D0%BB%D0%B5%D0%BD%D0%BD%D1%8B%D0%B5-blue)

> **Это концепт для хакатона, данные вымышленные.** Не официальный сервис вуза; логотип вуза не используется. Все персоны, оценки, заявки и расписание — вымышленные демонстрационные данные.

«Пара» — работающий прототип личного кабинета студента («деканат в кармане»): главный экран «Сейчас важно», расписание с переносами («было → стало» + push), успеваемость, заявка на справку как конечный автомат с таймлайном, уведомления, ведущие к объекту. Mobile-first от 360 px, светлая и тёмная темы.

## Стек

- **Бэкенд:** C++20, Drogon v1.9.14 (MIT), SSR на CSP-шаблонах; тонкие контроллеры, логика в сервисах.
- **БД:** SQLite (WAL), миграции применяются при старте приложения; PostgreSQL — опция роста.
- **Фронтенд:** CSP-шаблоны + чистый CSS на дизайн-токенах + htmx + Alpine.js (вендоренно, без npm-сборки и внешних CDN).
- **Инфраструктура:** Docker multi-stage, Nginx + systemd, бэкапы SQLite по cron.

## Запуск (3 команды)

```bash
git clone git@github.com:vertaler3/para.git && cd para
docker compose up --build
# открыть http://localhost:8080
```

> Примечание: файлы Docker (`Dockerfile`, `docker-compose.yml`) добавляются отдельным шагом этапа Э1 — тогда обе команды станут рабочими как есть.

## Демо-доступы жюри

Пять демо-аккаунтов (данные вымышленные) и единый демо-пароль — **появятся на шаге 6 Э1** (фикстуры `sql/fixtures.sql`); пароль публикуется в комментарии к работе, в репозитории и БД — только argon2id-хэши.

## Документация

Пакет решений лежит копией в `docs/` (канонические файлы — в рабочей области, в репозиторий не входят):

- `docs/01-продуктовое-решение.md` — продукт, сценарии С1–С8, DoD;
- `docs/02-техническое-решение.md` — архитектура, DDL, API, безопасность, деплой;
- `docs/03-дизайн-решение.md` — дизайн-система на токенах, вайрфреймы;
- `docs/04-обзор-зарубежных-open-source-проектов.md` — справочный обзор аналогов (во входные документы кодирования не входит);
- `docs/05-план-реализации-и-работа-с-ИИ.md` — этапы Э1–Э11, ролевая модель агентов;
- `docs/гайды/` — пошаговые дорожки BE/FE;
- `AGENTS.md` — живой файл продолжения работы (статус, команды, соглашения);
- `docs/decisions.md` — журнал решений; `docs/agents-log/` — журнал ИИ-сессий.

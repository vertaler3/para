## Ошибки/правки ИИ в ходе

- **Постановка неточна (шаг 1):** «таблицы teachers нет» — таблица создана 0002 (строки 16–20) и заполнена Э1; следствие то же (дублирующий ALTER из 02 §4.1 упал бы «duplicate column name»), отступление задокументировано Р-13 вместо молчаливого следования спеке.
- **Ловушка «Result» повторилась (шаг 2, ×2):** неквалифицированный `Result` в лямбдах member-функций внутри `namespace para` резолвится во вложенный `…Service::Result` (gcc: «has no member named 'empty'») — все `const drogon::orm::Result&` полностью (ScheduleService::eventsByTeacher + PeopleService ×8). Урок Э6-шага-4 не был поднят в общие правила — предлагается зафиксировать в шапке правил код-ревью.
- **Пропущенный ключ JSON (шаг 3, пойман юнит-тестом):** поле `works` копилось в счётчик, но не ставилось в объект дисциплины — чтение несуществующего ключа jsoncpp возвращает null молча; фикс `d["works"] = works`.
- **limit=0 обрезал рейтинг до нуля (шаг 3, пойман E2E при зелёных юнитах):** `maxRows=0` («без ограничения») в условии `size >= maxRows` срабатывал как «всегда break»; фикс `maxRows > 0 && …`.
- **Пересборка бинаря `para` обязательна для E2E (шаг 3):** после фикса пересобирался только para-tests — E2E показывал старое поведение при зелёных юнитах; отмечено как правило будущих шагов.
- **Гейт раунд 1 (две смысловые ошибки трактовки 02 §5.2):** (1) маска чужого ФИО ошибочно сужалась до рейтинга — «публичное поле (имя)» трактовалось как полное имя; исправлено маской на весь каталог (профиль + поиск); (2) «поиск студентов ограничен своим факультетом» ошибочно перенесён на рейтинг — рейтинг общий. Отклонённая альтернатива: прятать имя чужого полностью — противоречит «публичные поля (имя, группа, почта)».
- **Гейт раунд 2 (семантическая ошибка SQL):** LEFT JOIN включал в рейтинг студентов без оценок (среднего нет) — самозапрашивающий попадал в собственный рейтинг с полным ФИО; исправлено INNER JOIN — «рейтингуют только студенты со средним баллом». Отклонённая альтернатива: маскировать self — противоречит «полное имя — только в строке самого пользователя».
- **Р-15 уточнялась дважды** (раунды 1–2) — правило каталога и семантика рейтинга теперь записаны в `docs/decisions.md` в гейт-согласованной формулировке.

- `echo -n '<pw>' | argon2 '<соль>' -id -t 2 -m 19456 -p 1 -l 32` (форма из промпта) в пакете argon2 20190702 даёт «bad numeric input for -m»: `-m` — log2 памяти; рабочий ключ `-k 19456` (КиБ), encoded-строка каноническая. В CLI нет verify-режима (encoded воспринимается как соль и считается новый хэш) — верификация сделана мини-C на `argon2id_verify()` из libargon2 (функция шага 7).

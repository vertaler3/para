# 22.11.2022 — рейтинг: чужие ФИО полностью скрыты («М****»)

Запрос владельца: в рейтинге студентов скрыть других — «полностью фамилия
показана только у тебя, у других "М. Титова" должно быть "М****"», чтобы
рейтинг не был прямо опознаваемым.

## Правка

- `src/utils/NameMask.{h,cpp}`: новая чистая `maskRatingName(fio)` —
  инициал имени (первый не-пробельный символ после первого пробела — тот
  же принцип, что у `maskFullName`) + фиксированные `****`. Фамилия не
  отдаётся вовсе, число звёздочек всегда 4 — длина фамилии наружу не
  уходит. Одно слово → инициал первого слова; пустая/пробельная строка →
  пустая строка.
- `src/services/RatingService.cpp`: для чужих строк рейтинга
  `maskFullName` → `maskRatingName` (своё ФИО — полностью, как было);
  комментарий обновлён. Каталог людей (`/v1/people`) не тронут — там
  `maskFullName` («И. Фамилия») остаётся осознанно: поиск людей требует
  узнаваемости.

## Тесты

- `tests/unit/people_service_test.cpp`: +кейс `maskRatingName` («М. Титова»
  → «М****», разная длина фамилий → маска одной длины, одно слово,
  пустая/пробельная строка).
- `tests/unit/gradebook_rating_test.cpp`: ассерты чужих строк
  «М. Ливанов» → «М****» (4 места, включая raw-гейт-чек) и шапка файла.
- `docker compose --profile tests run --rm --build tests` → ctest 2/2,
  100% (счётчики — в AGENTS §6).

## Живая проверка (контур `up -d --build`)

- API (mark.demo): топ-5 = `М****, П****, А****, Л****, М****`;
  self-строка: `{'average': 83, 'fio': 'Ливанов Марк Сергеевич', 'rank':
  11, 'self': true}` — полное ФИО только у себя.
- Экран /rating (oleg.demo, 13-е место): список — все `М****/П****/…`,
  своя строка «Родионов Олег Павлович» с бейджем «вы» полная. Скрин —
  `gui-audit-2026-11-19/62-rating-masked.png` (вне репо).

## Следствие (осознанное)

Поиск «Найти в рейтинге» по фамилии чужих больше ничего не находит (в
списке фамилий нет) — работает только по инициалу/своей строке. Это
прямое следствие запроса на конфиденциальность; поиск людей остался в
разделе «Люди».

## Задача

Батч 3 Э7 — четыре последних экрана поверх каркаса и батчей 1–2:
«Заявки» (03 §4.5.1–4.5.5: каталог справок, форма 1–2 вопроса с
автосохранением черновика С2/С7, карточка с таймлайном и мини-диалогом
need_info, PDF), «Бронь аудиторий» (03 §4.9.5: каталог, сетка слотов дня
«свободно/занято/ваша бронь», подтверждение, «Мои брони» с отменой),
«Уведомления» (03 §4.6: лента с чипами-фильтрами, deep_link, «Прочитать
всё»), «Профиль» (данные /v1/me, настройки Э2, тема, ICS-подписка 5.4,
онбординг С5, QR-карточка студента и читательский билет 5.12, выход).

Отдельное решение батча — **замена QR-библиотеки**: qrcode.react —
React-компонент (JSX + рантайм), без npm-сборки не подключается;
вместо него вендорится vanilla qrcode-generator 1.5.0 (Kazuhiko Arase,
MIT) — **Р-21** в docs/decisions.md.

Ограничения всех четырёх постановок: данные — только существующие
контракты 02 §5.2 (SQL в контроллерах запрещён; `sql/` и `src/services/`
не тронуты, читались); правки чужих дорожек запрещены (config.json/
фильтры — BE, AGENTS §5.8); чужая правка `docs/01-продуктовое-решение.md`
в рабочем дереве ни одним коммитом не тронута и не закоммичена
(проверено `git status` при записи журнала — единственный модифицированный
файл вне этого док-коммита).

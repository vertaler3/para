# Журнал ИИ-сессии — Э1, правки по смок-тесту гейта (шаги 4–7), раунд 1

- **Дата:** 05.11.2026 · **Дорожка:** BE · **Промпт (суть):** «Гейт нашёл: идемпотентность сидирования (users: -1 → 0); смок login/me/logout false (login → 401 invalid_credentials). Найди причины, исправь, закоммити "Э1: правки по смок-тесту гейта, раунд 1". docker compose не запускай».

## Диагноз

Симптомы гейта (401 invalid_credentials на anya.demo, users=0 при «сидировании при старте», каскадное me=false/logout=false) — одна причина: ENTRYPOINT Dockerfile запускал `para --config /etc/app/config.json` **без `--seed`** (в Р-5 осталось неисполненное примечание «флаг добавим на шаге 6»; при закрытии шага 6 флаг в ENTRYPOINT/compose не добавили). Применялись только миграции 0001–0005 — таблицы есть, демо-данных нет: SELECT users по anya.demo пуст → 401 invalid_credentials, Set-Cookie не выдаётся → /v1/me и logout без сессии. Мой смок шага 7 прогонял бинарь с `--seed` вручную и пропустил контур запуска образа.

Поля гейта me401/wrong401/noDetails/rate429 уже были зелёными (фильтр, лимитер и 401-без-деталей работали и на пустой БД) — правок не требовали.

## Исправление

- `Dockerfile`: `ENTRYPOINT ["/opt/para/para", "--config", "/etc/app/config.json", "--seed"]` — демо-контур сеет фикстуры при каждом старте; идемпотентность — маркер 'fixtures' (Р-5): повторный старт на томе ничего не дублирует. Прод без демо-данных (Э9) — запуск без флага.
- `docs/decisions.md` Р-8 — фиксация решения.

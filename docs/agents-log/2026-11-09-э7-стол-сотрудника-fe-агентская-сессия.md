## Решения шага

1. **Перерисовка карточки — два запроса (POST API + GET фрагмента), не
   один.** Кнопки НЕ постят в страницу: данные меняет ТОЛЬКО API
   POST /v1/staff/applications/{id}/status (JSON-тело; htmx без
   json-encode расширения form-параметры не превратит в JSON-тело, а
   вендорить доп. файл — новая зависимость). После 200 карточку заменяет
   серверный фрагмент GET /staff/app-card (htmx.ajax, outerHTML) — так
   «POST status → htmx-перерисовка (фрагмент по HX-Request)» из
   постановки выполняется буквально, а клиентский билдер карточек и
   фрагмент договорились классами (проверено рендер-тестом обоих).
2. **409 — inline, карточка не перерисовывается:** статус не изменился —
   честнее показать message тела в слоте data-app-warn (aria-live), чем
   подменять карточку; 5xx — тост (fetchJSON-семантика каркаса).
3. **Очередь/сводка/лента — клиент-fetch (не SSR):** постановка
   именует API GET /v1/staff/applications и /v1/staff/dashboard как
   источники очереди/дашборда; это даёт требуемые состояния 03 §5
   (скелетон/пусто/ошибка/офлайн) и чипы-фильтры без перезагрузки
   страницы. Прецедент — дашборд «Сегодня» (views/dashboard.csp).
4. **Фрагмент из ApplicationsService::queue без фильтров + фильтр по id
   в памяти контроллера:** одного строкового метода с owner/overdue в
   сервисе нет, src/services/ — BE-дорожка; SQL в контроллере запрещён —
   переиспользуем ТОТ ЖЕ метод, что за JSON API (02 §5.2), вычленяя
   строку по id. Ответ POST статуса (card без owner/overdue) для
   перерисовки не годится — в карточке есть владелец и «Срок горит».
5. **StaffFilter НЕ на страницу:** страница и фрагмент отвечают HTML;
   JSON 403 фильтра остался только на /v1/staff/* (проверка роли
   контроллером — fail-closed, как в фильтре; отсутствие атрибута
   сессии невозможно — LoginFilter выше по цепочке роута).
6. **Таб-бар студенческий, без активного таба:** «табы сотрудника, свой
   набор» (03 §4.8) не собирались — вместо мёртвых ссылок чипы-якоря
   по секциям; на ≥1024px студенческая навигация видима как обычно.

## Ошибки ИИ, пойманные и исправленные в ходе

1. **Коллизия `Result` (главная серия ошибок компиляции):** в member-функциях `ApplicationsService` unqualified `Result` в лямбдах резолвится в вложенный `ApplicationsService::Result`, а не `drogon::orm::Result` (scope класса активен; GradesService.cpp поэтому везде пишет `drogon::orm::Result`). Каскад «no match for call to lambda» в SqlBinder.h:273. Исправлено квалификацией во всех лямбдах cpp.
2. **Незахваченный `eventId`** в цепочке лямбд apply() (capture-список средней лямбды не включал переменную из тела функции — «eventId is not captured») и в `fetchEventById` — добавлены захваты.
3. **ГЛАВНАЯ НАХОДКА ШАГА — биндинг `$N` в SQLite:** юнит-тесты messages падали («заявка исчезла» при существующей заявке). Диагноз временным probe-кейсом в реальной сборке: **в SQLite `$N` — имя параметра, индекс назначается по первому вхождению в текст SQL (не как у `?N`)**, а drogon биндит аргументы позиционно (i+1). В `INSERT..SELECT … SELECT … $2, $3 … WHERE id = $1` текст `$2,$3` стоит раньше `$1` → `applicationId` улетел в слот `$2` (comment), а в `WHERE id` попал `authorId` → INSERT..SELECT молча вставил 0 строк (affectedRows=0, без ошибки). Весь прежний SQL проекта перечисляет `$1` первым — потому не проявлялось. `insertPlainMessageEvent` переписан без трюка INSERT..SELECT (SELECT статуса внутри транзакции + INSERT..VALUES `$1..$5` по порядку); в коде и журнале — правило «порядок $N в тексте обязан совпадать с порядком биндинга».
4. **Ошибка E2E-сценария (не сервера):** в первом прогоне части 2 PUT/messages на id 4/5 дали 404 — заявки в свежей БД не создавались (только фикстуры 1–3); повторный прогон с созданием заявок — 200/409/201 как ожидалось. Поведение сервера (404 на несуществующий id) корректно в обоих прогонах.
5. **Мусор в тесте** (`appStatusOf`-заглушка, unused `err`, `auto bad = broken.db`) и неиспользуемый `sendBadRequest` в контроллере — убраны. Временный probe-кейс SIGSEGV-ил из-за захвата по ссылке в колбэках, доживающих до конца тест-кейса, — артефакт probe, в сервисах такого захвата нет; удалён.

Поймано первой же командой; проверка `hub.docker.com/v2/repositories/drogonframework/drogon/tags` → валиден `v1.9.14`. Зафиксировано в Р-2 — на шаге 3 Dockerfile использован `v1.9.14`.
2. **«Базовый образ скачан заранее» не подтвердилось**: `docker images` был пуст — образ скачан в сессии (`docker pull drogonframework/drogon:v1.9.14`).
3. **Первый `docker run` завис** в статусе Created на холодном старте Docker VM (>2 мин без вывода) — диагностировано `docker ps -a`, остановлено; после `hello-world` (прогрев) повторный запуск прошёл нормально.
4. **Проверка линковки была неполной**: `ldd | grep 'ssl|sqlite'` показал только 2 системные библиотеки → преждевременный вывод «в рантайм ничего копировать не надо». Полный `ldd` на шаге 3 (см. следующую запись) выявил ещё 5 зависимостей — поправка внесена в Р-4. Урок: зависимость бинарника перечислять полным `ldd`, не grep'ом по избранным именам.

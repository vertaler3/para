## Ошибки и фиксы по ходу

- `<%inc file="x.csp" %>` не подключает шаблон — текст директивы попадает в
  сгенерированный C++ (синтаксис перепроверен по исходнику create_view.cc
  v1.9.14); перешли на `<%view %>`.
- `{{ }}` не существует в v1.9.14 — гайд FE и 02 §6.4 описывали не ту
  версию; синхронизированы позже (раунд 2 ревью).
- Комментарий внутри `<%c++ %>`, содержащий `%>`, закрывает блок раньше —
  текст утекал в C++ (поймано компиляцией head.cc); правило: без `%>` в
  комментариях csp-блоков.
- `std::any_cast<const std::string*>(&any)` возвращает указатель на
  указатель — звёздочки перепутаны; правильно `*std::any_cast<std::string>(&any)`
  (поймано компиляцией).
- `HttpViewData::get<T>` безопасен (нет ключа → статический T(), не тот тип →
  «Bad type» в лог и дефолт); operator[] const возвращает std::any& —
  проверка typeid перед any_cast.

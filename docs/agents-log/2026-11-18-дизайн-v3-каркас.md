### Расхождения с решениями (вердикты — Р-31 в `docs/decisions.md`)

- **(а) Тёмная тема.** В прототипе нет ни `prefers-color-scheme`, ни `[data-theme=dark]`;
  в проде тема — настройка `settings.theme` (system/light/dark) с прод-тёмной темой.
  **Решение:** тёмная выводится инверсией navy-палитры по правилам прод-тёмной
  (ступени фона того же тона, светлый текст, `--primary` — светлый тинт с тёмным
  `--on-primary`, тени e1/e2 гасятся); оба механизма (системный + ручной) сохраняются.
  Значения и WCAG-расчёт — шаг 3.
- **(б) Нижний таб-бар.** Постановка утверждала, что его в прототипе нет. **Проверка
  CSS прототипа это опровергает:** базовое правило `.primary-nav{position:fixed;bottom:0;…;
  padding:6px 4px calc(6px + env(safe-area-inset-bottom))}` — это и есть нижний
  таб-бар на <1024px; на ≥1024px он становится строкой в шапке, на ≥1100px — navy-
  сайдбаром слева (+ `campus-nav` «В кампусе», `sidebar-foot`). Медиа max-width
  599/649/679/699 правят только плотность, вход и тост (тост — `bottom:calc(82px +
  safe-area)`, т.е. над таб-баром). **Решение:** принять схему прототипа — она
  совпадает с прод-таббаром по составу (5 пунктов) и семантике (`aria-current`);
  DOM `primary-nav` переезжает внутрь `site-header` (как в прототипе), отдельный
  `partials/tabbar.csp` становится пустым совместимым партиалом.
- **(в) Переключатели языка/темы.** В прототипе их нет. **Решение:** фичи 5.18
  сохраняются полностью: язык — компактный переключатель в footer на всех экранах
  (включая вход) + сегмент в профиле; тема — сегмент в профиле; разметка в
  стилистике прототипа (`.segmented`/`.footer-links`).
- **(г) Витрины** `index/prototype/developer/components.html` — в прод не
  переносятся (см. карту).
- **(д, найдено сверх постановки)** Прототип хардкодит русские строки в CSS
  (`.primary-nav:before{content:'МОЁ ПРОСТРАНСТВО'}` на ≥1100px) и ссылки
  `href="profile.html"` в селекторах. **Решение:** такие правила при переносе
  переписываются: подпись — из словаря в DOM (`workspace-label`), селекторы — по
  классам/`data-*`, не по href (иначе en/zh покажут русский текст — нарушение 5.18).
- **(е, найдено сверх постановки)** Шрифтовой стек прототипа `Inter,Arial,sans-serif`
  уже́ прод-стека 5.18 → сохраняется прод-стек с CJK-цепочкой (Arial добавлен, ничего
  не удалено).

## Что сделано

- `src/services/PasswordHasher` (argon2id_hash_encoded/verify, t=2, m=19456, p=1, тег 32; соль 16 байт OpenSSL), `src/services/SessionService` (токен 128 бит hex; INSERT/SELECT/DELETE sessions параметризованным SQL; чистка истёкших; единый хелпер cookie с HttpOnly; Secure; SameSite=Lax; TTL 30 сут, env PARA_SESSION_TTL_HOURS), `src/utils/LoginLimiter` (3 неудачи → 15 с, удвоение до 900 с, сброс по успеху; часы параметром — тестируемо), `src/controllers/AuthCtrl` (POST /v1/auth/login, POST /v1/auth/logout, GET /v1/me, GET /login — рендер шаблона; 401 без деталей, 429 + Retry-After; зеркало failed_attempts в users), `src/filters/LoginFilter` (публичные пути + валидация сессии; сессия кладётся в attributes).
- `views/login.csp` — семантическая разметка по 03 §4.1 без стилей; `CMakeLists` — libargon2 (find_path/find_library), drogon_create_views (генерация в build-каталог), новые файлы в para/para-tests; `tests/unit/auth_unit.cpp` (hasher round-trip + параметры в encoded; лимитер 15→…→900, сброс, независимость логинов).
- `config.json` (enable_session=false — своя таблица; комментарии), `env.example` (PARA_DEMO_PASSWORD, PARA_SESSION_TTL_HOURS, PARA_DB_PATH; убран неиспользуемый PARA_SESSION_SECRET), `Dockerfile` (+libargon2-dev в build-стадии), `docker-compose.yml` (сервис tests: profiles [tests], target build, cmake+Ninja+ctest).

## Ошибки/уточнения, учтённые в ходе

- libargon2-dev в build-образе drogon отсутствовал (только runtime libargon2-1) — добавлен в Dockerfile; лицензия сверена по /usr/share/doc/libargon2-1/copyright (phc-winner-argon2, CC0/Apache — совпадает с 02 §2.2).
- Типы DbClient: `drogon::orm::DbClientPtr/Result/DrogonDbException` (namespace orm, HttpAppFramework.h их не тянет) — первая сборка упала, квалифицировано.
- drogon_create_views нельзя вызывать до add_executable (target_sources по несуществующей цели) — перенесён после цели.
- Скомпилированный .csp — DrTemplate, роут сам не создаёт → 404 на /login; страницу отдаёт тонкий GET /login в AuthCtrl (newHttpViewResponse("login")).
- registerFilter для HttpFilter<T> запрещён static_assert'ом (автосоздание Drogon) — фильтр регистрируется автоматически по имени класса, явный вызов убран.
- Тест лимитера ловил ошибку отсчёта времени в самом тесте (блок начинается в секунду 3-й неудачи) — исправлен тест, не реализация.

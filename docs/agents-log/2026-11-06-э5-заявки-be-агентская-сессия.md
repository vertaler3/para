## Ошибки/правки ИИ в ходе

- **$N-биндинг SQLite (шаг 2, поймано юнит-тестами):** `$N` — имя параметра с индексом по первому вхождению в текст SQL (не как `?N`), а drogon биндит аргументы позиционно — `INSERT..SELECT` с `$2,$3` раньше `$1` молча вставлял 0 строк; переписано, правило «порядок $N в тексте = порядку биндинга» зафиксировано в комментариях и журнале шага.
- **Форма машинного маркера (шаг 4):** постановка предполагала hex UTF-16BE (FEFF0414…); пробник v2.4.6 в контейнере + юнит-тест установили: при HPDF_UseUTFEncodings libharu v2.4.6 пишет строки Info-словаря ЛИТЕРАЛОМ с OCTAL-эскейпами UTF-8 («\320\224\320\225\320\234\320\236» = «ДЕМО»), FEFF0414… в файле нет; маркер детерминирован пином v2.4.6 и охраняется тестом.
- **Гейт, раунд 1 (false: возвратВРаботу, pdfШтамп):** (1) серверный возврат С7.6 работал (воспроизведён точным сценарием гейта: staff need_info → 201 messages → sqlite/GET `in_progress`), но 201-ответ messages не нёс статуса заявки — добавлено поле `application_status` (`src/services/ApplicationsService`); (2) октал-эскейпы «ДЕМО» находятся только СЫРЫМ поиском — при декодировании PDF-текста их нет (python-проба: raw find octal=185, ascii=374; decoded «ДЕМО»=−1, DEMO-FAKE-DATA=189) — канон машинного маркера: ASCII-хвост `DEMO-FAKE-DATA` (`kStampMarker` в `src/services/PdfBuilder.h`); Р-12 дополнена; полный E2E-прогон цепочки после правок — зелёный по всем пунктам. Коммиты `42be376`, `72dd9ba`; журнал — `docs/agents-log/2026-11-06-э5-правки-по-гейту-раунд-1.md`.
- **Гейт, раунд 2 (те же два false):** оба false повторились на образе без коммита `42be376` — вывод «гейт шёл на старом бинаре» (прецедент Э3 раунд 2); машиночитаемая проба свежести — `/Subject para-e5-gate-r2` (`HPDF_SetInfoAttr(pdf, HPDF_INFO_SUBJECT, kBuildTag)`, `src/services/PdfBuilder.cpp:170`): нет строки в PDF — проверка шла по старой сборке; дополнительно: `revealKeywordsUtf8` перезаписывает /Keywords сырыми UTF-8 байтами «ДЕМО…» на месте с сохранением длины (xref не сдвигается — `src/services/PdfBuilder.cpp:200`), потоки несжаты (HPDF_COMP_NONE, `:95`), 201-ответ messages дополнен алиасом `status` (дубль `application_status`); на свежем коде полный прогон цепочки — зелёный по всем пунктам, включая оба false. Коммит `314dee5`; журнал — `docs/agents-log/2026-11-06-э5-правки-по-гейту-раунд-2.md`.
- **Мелкое (раунд 2, поймано сборкой):** свободная функция `revealKeywordsUtf8` не видела член класса — «‘kStampText’ was not declared»; исправлено квалификацией `PdfBuilder::kStampText`.

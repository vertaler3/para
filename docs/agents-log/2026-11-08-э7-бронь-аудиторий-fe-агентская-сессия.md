## Решения шага

- **Отмена брони — только из «Моих брони»**, не тапом по mine-слоту:
  GET /v1/rooms/{id}/slots отдаёт {starts_at, ends_at, state} без id
  брони (02 §5.2) — тап по mine-слоту не может открыть диалог отмены
  без своего lookup-запроса. Компромисс: серая зона вайрфрейма (03 §4.9.5
  «ваша бронь — акцент с отменой») закрыта списком «Мои брони» (там
  id есть) — постановка этого батча описывает отмену именно там.
- **Пустой каталог при фильтре вместимости** — muted-строка «Аудиторий с
  такой вместимостью нет — смягчите фильтр» на месте чипов (текста
  03 §5.2 для этого случая нет; состояние «пусто» постановки относится к
  сетке и «Моим брони»).
- **Перерисовка сетки после ЛЮБОГО исхода POST** (не только конфликтов):
  после 201 слот стал mine; после slot_taken/conflict/blocked — данные
  могли устареть; после 404 — каталог перечитывается. Тихая перечитка
  (silent) без скелетона — сетка не мигает, заменяется по ответу;
  «Мои брони» перечитываются вместе с ней (после 201 и после отмены).
  После успешного DELETE сетка тоже тихо перечитывается — слот мог
  освободиться.

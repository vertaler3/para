## Ошибки ИИ, пойманные и исправленные в ходе

1. **Ключевое открытие шага — формат Info-строк:** постановка предполагала «KEYWORDS → hex UTF-16BE»; пробник показал `FEFF0414…` НЕ найденным: v2.4.6 с `HPDF_UseUTFEncodings` пишет Info-литерал с OCTAL-эскейпами UTF-8. Первый поиск не нашёл и «KEYWORDS» — grep регистрозависимый (`/Keywords` с заглавной только K); нашёл по hexdump смещения 0xa6. Маркер переопределён на фактические байты, способ зафиксирован в коде/Р-12, юнит-тест охраняет.
2. **`-x c++` в g++ перекинулся на libhpdf.a** («stray '`' in program») при компиляции пробника — файл переименован в .cpp (компиляция по расширению).
3. **Незахваченные значения в лямбдах** (тот же класс, что шаги 2–3): в PdfCtrl `session.userId` использовался внутри двойного вложения guard→one() — вынесен в `const int64_t userId` и захвачен в обе лямбды; ошибка сборки поймана контейнером.
4. **doctest `FAIL` без `operator+`** — MessageBuilder поддерживает `<<`-цепочки, не конкатенацию: `FAIL("...", font, "...")`.
5. `-Wall -Wextra` чисто в файлах шага с первого прохода (бинарных warnings нет).

- **Дата:** 08.11.2026 · **Ветка:** `fe_be_connect_glm` · **Агент:** верстальщик-людей (workflow, FE-дорожка Э7)
- **Постановка:** экран «Люди» — GET /people (каталог-поиск: input, чипы ролей Все|Преподаватели|Студенты|Сотрудники, debounce ~300 мс) + GET /people/{id} (профиль, ветвление преподаватель|сотрудник / чужой студент), оживление ссылок из sheet «Детали пары» (/people/{teacher_id+1000} — Р-15, ссылка стоит с экрана «Расписание»). Один коммит экрана; sql/ и src/services/ не трогать.

## Что сделано

1. **`src/controllers/PeopleCtrl.{h,cpp}`** — страничная плоскость (документация в шапке заголовка, паттерн ApplicationsCtrl.h):
   - `GET /people` → views/people.csp — страница без данных (паттерн notifications.csp); результаты грузит клиент из ТЕХ ЖЕ JSON-роутов `/v1/people/search` (уже существовали — Э6а); LoginFilter (303 без сессии — Р-20); activeTab пустой («Люди» — не таб).
   - `GET /people/{id}` → views/person.csp — **path-id БЕЗ OwnershipGuard** (задокументировано в шапке: people — общий каталог, 403 в people-роутах не возникает — Р-15; чужой студент легально 200 с урезанными полями, маскирование на сервере; DoD №2 остаётся на собственных роутах оценок/заявок/броней). id приходит **строкой** и валидируется контроллером: **нечисловой/переполнение → 404 HTML-карточка** (постановка страницы; JSON-роут /v1/people/{id} отвечает 400 средствами drogon — контракты плоскостей разные, оба задокументированы). Тело страницы — **PeopleService::profile (тот же метод, что за JSON API)** — NotFound → 404 карточка, Error → 500 fail-closed; статус-код на ответе настоящий (200/404/500), карточка — HTML, не голый JSON (паттерн application.csp: режимы mode=data|notfound|dberror).
2. **`views/people.csp`** (новый, drogon_ctl create view) — input type=search + 4 чипа роли (словарь 02 §5.2), состояния 03 §5 в разметке: скелетон (3 × .skeleton.card), подсказка пустого запроса («Начните вводить…» + «Преподаватели»), пусто («Никого не нашли»), ошибка с «Повторить», результаты. Синтаксис v1.9.14 ({{}} нет, Р-16) — страница статична.
3. **`views/person.csp`** (новый, drogon_ctl create view) — SSR-шапка с ветвлением **по данным ответа** PeopleService::profile:
   - teacher|staff → полное имя, должность · кафедра, почта + mailto-кнопка «Написать», кабинет ссылкой **`/map/rooms?q=<номер>`** (номер вырезан из «Корпус А, ауд. 3032» — алиас страницы карты сделает отдельный коммит этой же группы; ссылка живёт уже сейчас по постановке), блок «Занятия»;
   - student → имя КАК ПРИШЛО (чужой — уже маскированное «И. Фамилия» сервером, Р-15), «Студент · группа N», почта **без** mailto-кнопки, «Расписание группы» — и **БЕЗ** блоков оценок/заявок (их нет и в данных ответа — ветвлению нечего рисовать, 02 §5.2);
   - свой студент (в ответе есть faculty/program/course) — дополнительно строка меты «факультет · курс · программа» (данные-ветвление, отдельной ветки не нужно);
   - блок «Занятия»/«Расписание группы» — клиентский fetch GET /v1/people/{id}/schedule со своими состояниями (скелетон/пусто/ошибка+«Повторить»); day-caption + .schedule-list/.lesson каркаса, статусы как на «Расписании» (.lesson.moved/.cancelled).
4. **`static/js/app.js`** — секции «Люди» (поиск: debounce 300 мс, монотонный seq против гонки устаревших ответов, скелетон только при ответе >300 мс — 03 §5.1, чипы aria-pressed, пустой запрос → search без q role=teacher — сервис отдаёт каталог целиком: `($1 = '' OR ... LIKE $1)`, сверено с PeopleService::search) и «Профиль человека» (schedule-блок: группировка по дате UTC, fmtDay без сдвига пояса, статусы moved/cancelled; «Повторить» dberror — перезагрузка). Вставка — только createElement/textContent (02 §6.4); createContextualFragment — только статические svg-константы.
5. **`static/css/app.css`** — секция экрана: `.people-list` (паттерн каркасных списков — новые цветовые пары НЕТ, Р-16), строки — каркасное .list-row.

## Ошибки и фиксы по ходу

- **UTF-8 байт-арифметика в person.csp (поймано рантайм-рендером, не компиляцией):** `initialsOf` считал БАЙТЫ (`out.size() >= 2`) → аватар пустой (половины кириллических букв); `roomNoOf` сдвигался от `find("ауд.")` на 4 «символа» вместо 7 байтов needle → `q=д` вместо `q=3032`. Переписаны на lead-байт + continuation (10xxxxxx) / `needle.size()`.
- `(void)req` при безымянном параметре — поймано `-fsyntax-only -Wall -Wextra` контейнера; параметр назван.
- Тест-ожидания рендера: «МК»→«КМ» (инициалы = первые буквы первых двух слов, как в каркасном profile-JS), «Заявки» убрана из mustNotHave (пункт таб-бара, не блок страницы), staff → «Написать» есть (staffLike включает сотрудника).

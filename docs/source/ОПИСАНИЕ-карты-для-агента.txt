ОПИСАНИЕ ИСТОЧНИКА «КАРТА УНИВЕРСИТЕТА» (для агента фронтовой дорожки «Пара»)
================================================================================

ЧТО ЭТО ЗА ПАПКА
----------------
«Карта Университета.html» + папка «Карта Университета_files/» — сохранённая
копия страницы интерактивной карты кампуса РЕАЛЬНОГО вуза. Это ТОЛЬКО СПРАВОЧНИК
механик и структуры: источником данных для «Пары» она быть не может.

ВАЖНО (правило §5.1 AGENTS.md): концепт «Пара» использует только вымышленные
данные. Из этой копии берём ИДЕИ ИНТЕРФЕЙСА, а не контент: никаких логотипов,
названия реального вуза, ссылок на его сайт, реальных текстов и имён. Бейдж
«концепт для хакатона, данные вымышленные» обязателен.

КАК УСТРОЕНА РЕАЛЬНАЯ СТРАНИЦА (механики)
-----------------------------------------
1. Форма «Найти на карте»: строка поиска (параметр q=) + два селекта:
   - «корпус»: Корпус А, Корпус Б, Корпус В, Корпус Г, Новый корпус, Библиотека,
     Столовая, Спортцентр и бассейн, Общежитие №2 (9 объектов);
   - «этаж»: список этажей выбранного корпуса (подгружается динамически).
2. Быстрые подсказки над поиском (популярные объекты): «Парковки», «Столовая»,
   «Спортцентр и бассейн» — клик = поиск по этому слову.
3. Каждый корпус имеет короткий код (building=a/b/v/g/n/s/d/l/r) — карта
   открывается прямой ссылкой с выбранным корпусом.
4. Побочные страницы: «Кампус» (текстовое описание корпусов), «Общежития»,
   «Схема парковок» (отдельная картинка-схема).
5. Планы этажей с кабинетами — интерактивная графика (грузится с сервера,
   в сохранённой копии её НЕТ; в папке только оболочка и ассеты оформления).

ЧТО ПЕРЕНОСИМ В «ПАРУ» (идеи интерфейса, данные — только из наших API)
----------------------------------------------------------------------
1. Механика «выбрать корпус → выбрать этаж → список кабинетов» — уже есть
   в нашем /map (GET /v1/map/buildings → чипы этажей → GET /v1/map/rooms),
   сверить вёрстку с этим паттерном.
2. Поиск кабинета по номеру (у нас: GET /v1/map/rooms?q=1207 → «Корпус Б ·
   этаж 2 · тип») — как в реальной карте строка «Найти» с q=.
3. Идея «быстрых объектов»: в реальной карте это Столовая и Спортцентр.
   У нас из cross-link: «Столовая» → /canteens, «Библиотека» → /library,
   «Мои брони» → /rooms. Можно оформить как блок быстрых ссылок под поиском
   на /map (только ссылки на СУЩЕСТВУЮЩИЕ страницы проекта!).
4. Объекты карты ≠ только учебные корпуса: в реальной карте отдельными
   пунктами карты являются библиотека/столовая/общежитие. В наших фикстурах
   корпусов 3 (А/Б/В) и кабинеты фиксированы (1207, 3105, Б-204 и др.) —
   НЕ выдумывать объекты, которых нет в GET /v1/map/buildings.
5. Прямые ссылки с параметрами: у нас уже есть алиас /map/rooms?q=1207 —
   использовать его для cross-link из профилей преподавателей (кабинет).

ЧЕГО НЕ ПЕРЕНОСИМ
-----------------
- Логотипы/бренд/название реального вуза (в ассетах есть logo-mgimo-main.svg —
  не использовать).
- Ссылки на реальный сайт, реальные тексты страниц, ФИО.
- Парковки/общежития/панорамы — в наших данных таких сущностей нет; не рисовать.
- Стили оформления реальной страницы (main_new.css и пр.) — у нас свои токены.

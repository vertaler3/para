# Демо-ролик «Пара» — сценарий для жюри (ровно 5:00)

Съёмка с телефона, живой сайт **https://para-student.ru**. Два телефона: №1 — студент, №2 — сотрудник деканата. Экран «Сейчас важно» (01 §5.1) в интерфейсе v3 — **«Сегодня»**; навигация: «Сегодня · Расписание · Учёба · Заявки · Профиль».

## Чеклист подготовки съёмки

- **Телефоны:** два смартфона от 360 px, запись экрана, авто-блокировка выкл., яркость ~70 %, «Не беспокоить».
- **Аккаунты:** вход — дублем через «Демо-доступы для жюри» на `/login`; пароль единый из комментария к работе, вводим руками. Телефон №1: anya.demo (0:00) → dina.demo (1:10) → mark.demo (2:30) → oleg.demo (≈4:10); №2: dean.demo с 3:30. Перед дублем — выход из прошлой сессии.
- **Сеть:** `/healthz` → «ok», вход всех пяти аккаунтов (Э10); резервный LTE.
- **Тема/язык:** до 4:30 — светлая тема и «Рус»; переключение — только в финале.
- **Данные:** переносы 1-ФМО в фикстурах — в прошлом (последний 17.11): бит «было → стало» снимаем уведомлением с deep-link на день переноса (04.11); для 3:30 выписать id будущего события 1-ФМО — **33** («Мировая экономика», 24.11, ауд. 3024): select формы берёт 5 свежих изменений других групп — вводим в поле «или id события вручную».
- **Звук:** закадр пишется отдельно; проверить, что колокольчик обновляется (WebSocket).
- **Хронометраж:** репетиция по блокам, запас +7 с на блок, монтаж до ≤5:00.

## Раскладка по секундам

### 0:00–0:30 · Проблема + вход — anya.demo
Тапы: телефон №1 → `para-student.ru` → редирект на `/login` → «Демо-доступы для жюри» → тап **anya.demo** (логин подставился) → пароль → **«Войти»** → экран **«Сегодня»**.
Закадр: «Расписание переносят в чатах, справки — в окошко. «Пара» — деканат в кармане; пароль единый — в комментарии к работе».

### 0:30–2:30 · «Сегодня» → перенос из уведомления → справка — anya.demo, затем dina.demo
Тапы (0:30–1:10, anya): **«Сегодня»** — виджеты «Следующая пара», дедлайны, заявки → колокольчик → **«Уведомления»** — строка **«Пара в 10:00 перенесена в ауд. 4210»** → тап (deep-link) → **расписание дня 4 ноября**: блок «Перенос аудитории: было 3024 → стало 4210» → **«Подробнее о переносе»** — диалог «Мировая экономика 10:00–11:30 · Перенос аудитории».
Закадр: «Один экран отвечает на вопрос „что сегодня“, уведомление ведёт прямо к паре: было 3024 — стало 4210».
Тапы (1:10–2:30, смена на dina.demo): «Сегодня» → виджет **«Ваши заявки · 1 в работе»** → **«Заявки»** (карточка «Академическая справка», мини-прогресс) → **«Новая заявка»** → каталог **«Какой документ нужен?»** → «Справка об обучении» → форма: профиль подставлен, выбираем «2 экземпляра» и «В деканате» → **«Сохранить черновик»** → «Назад» → повторно «Новая заявка» → тип → плашка **«Черновик восстановлен»**, поля на месте → **«Отправить заявку»** → «Заявка отправлена», таймлайн, «обычно до 3 рабочих дней».
Закадр: «Справка — три касания после раздела: документ, два вопроса, отправить. Черновик живёт на сервере — форма пережила закрытие».

### 2:30–3:30 · Успеваемость → зачётка → рейтинг → бронь — mark.demo
Тапы: вход mark.demo → **«Учёба»**: средний, у «Мировой экономики» красная строка «До допуска не хватает 4», пересдача «История МЭО, 18 ноя» → **«Зачётная книжка»**: средний за всё время, поиск «эко» → «Дисциплин: 2 из 6» → **«Посмотреть рейтинг»**: чужие имена — «И. Фамилия», подпись «Чужие имена сокращены» → **«Моя строка»** → «Профиль → Ваш кампус → Бронь аудитории»: аудитория, дата → тап слота → **«Забронировать 10:00–11:00»** → «Забронировано: Ауд. …».
Закадр: «Перед сессией видно, где не хватает баллов. Рейтинг не раскрывает чужих имён, аудиторию бронишь в два тапа».

### 3:30–4:30 · Стол сотрудника: конвейер, PDF, перенос → push; 403 — dean.demo + dina/oleg.demo
Тапы: телефон №2, dean.demo → «Сегодня» → карточка **«Стол сотрудника»** → **«Открыть»** → `/staff`: сводка «Новые заявки · Приняты · В работе · Ждут ответа · Готовы к выдаче» и «Свежие изменения расписания»; очередь с метками «Срок горит» → свежая заявка Дины «Академическая справка» (из блока выше) → кнопки **«Принята» → «В работе» → «Готова»** (каждая — авто-push автору). Телефон №1 (dina): колокольчик — «Академическая справка: Готова» → **«Документ готов»** с водяным знаком «ДЕМО · вымышленные данные» → **«Скачать PDF»** со штампом. Телефон №2: чип **«Перенести пару»** → форма «Перенести занятие»: в поле «или id события вручную» вводим 33, действие «Перенести», «Стало» — ауд. 4210 → **«Сохранить перенос»**. Телефон №1, смена на oleg.demo: колокольчик — **«Пара перенесена: Мировая экономика»** (пришло обоим — группа 1-ФМО) → в адресной строке открыть `/applications/1` (заявка Дины) → нейтральная карточка «Не нашли то, что искали» — сервер ответил 403.
Закадр: «Сотрудник ведёт заявку кнопками — студенту уведомления, PDF со штампом демо. Перенос разлетается группе. Чужой id не откроется — доступ только к своим данным».

### 4:30–5:00 · Новости, языки, тёмная тема, бейдж — oleg.demo, телефон №1
Тапы: **«Новости»** (`/notifications?segment=news`) → раскрыть новость на 中文 («Читать полностью», «Как пройти» → карта) → подвал: **«Рус · EN · 中文»** → «EN» — интерфейс перерисовался → «Профиль → Оформление» → **«Тёмная»** — тема сменилась повсюду → финальный кадр: бейдж «концепт для хакатона, данные вымышленные · Не является официальным сервисом вуза».
Закадр: «Новости и интерфейс — на трёх языках, тёмная тема для вечерней сессии. Это концепт: данные вымышленные».

## Стоп-лист (что не показываем)

- Инструменты разработчика, сетевые запросы, curl, код — только живой интерфейс (403 — карточкой UI, не консолью).
- Демо-пароль — не называть вслух и не выводить в титры.
- Реальные ФИО, логотип вуза — данные вымышленные; бейдж концепта в кадре на входе и в финале.
- Неверный пароль и блокировку входа (429).
- Приватную ICS-ссылку — токен не показывать целиком.
- Витрины состояний (`?state=`), демо-кнопки прототипа, непродовые экраны.
- Чужие черновики и оценки «в открытую» — кроме шага 403, где портал сам отказывает.
